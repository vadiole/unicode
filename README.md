# Unicode – characters and emoji

An Android app with a Unicode character table containing letters from different writing systems, accented letters and diacritics, punctuation, mathematical symbols, emoji and other special characters. Explore familiar scripts or find aesthetic characters for names and text.

## Find a character

- Search by name, paste a character to identify it, or enter a code point such as `U+0394`, `0x0394` or `\u0394`.
- Jump directly to a Unicode block instead of scrolling through the whole table.
- Use the fast scrollbar to move quickly through the character table.
- Revisit recent characters without searching again.

## Inspect the details

- Touch and hold a character to open detailed information.
- View the character’s name, code point, Unicode block and version, and its HTML and CSS representations.
- Pinch to zoom in and inspect the character’s shape.
- Identify invisible and control characters by their visible abbreviations.

## Build a collection

- Tap characters to add them to the Unicode pad in the bottom bar, then touch and hold the pad to copy them together into another app.

## Offline and device support

- The character database is included in the app, so it works offline.
- Character appearance depends on your device and its fonts.
- Older Android versions may not display newer characters and emoji.
